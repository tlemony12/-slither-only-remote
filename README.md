# Slither Online

เกมงูออนไลน์ ห้องละสูงสุด 10 คน — เซิร์ฟเวอร์ตัวเดียวเสิร์ฟทั้งหน้าเกมและ WebSocket ใครมีลิงก์ก็เล่นได้ (ไม่ต้องล็อกอิน)

## รันในเครื่อง
```
npm install
npm start
```
เปิด http://localhost:3000 (เพื่อนใน Wi-Fi เดียวกันเปิด http://IP-เครื่องคุณ:3000)

## ปล่อยให้คนทั่วโลกเล่น (ตัวอย่าง Render.com ฟรี)
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub
2. render.com → New → Web Service → เลือก repo
3. Build Command: `npm install` · Start Command: `npm start`
4. ได้ลิงก์ `https://ชื่อ.onrender.com` ส่งให้ใครก็เล่นได้ (แพ็กเกจฟรีจะหลับเมื่อไม่มีคนใช้ ครั้งแรกอาจรอ ~30 วินาที)

ใช้ Railway / Fly.io / Glitch / VPS ก็ได้เหมือนกัน (ต้องรองรับ Node.js 18+ และ WebSocket) เซิร์ฟเวอร์อ่านพอร์ตจากตัวแปร `PORT`

## การทำงานของห้อง
- เปิดลิงก์ธรรมดา → ระบบจัดเข้าห้องอัตโนมัติ (ห้องที่ยังไม่เต็มและมีคนมากสุดก่อน)
- `https://ลิงก์ของคุณ/?room=รหัส` → ห้องเฉพาะกลุ่ม (ปุ่ม "คัดลอกลิงก์ชวนเพื่อน" ในเกมสร้างให้)
- ห้องเต็ม 10 คนจะไม่รับเพิ่ม · ถ้ามีคนไม่ถึง 6 ตัว ระบบเติมบอทให้ และถอนบอทเมื่อมีคนเข้ามา
- เซิร์ฟเวอร์เป็นผู้คำนวณทุกอย่าง (กันโกง) อัปเดต 20 ครั้ง/วินาที

ปรับค่าได้ที่ต้น `server.js`: `MAXP` (คนต่อห้อง), `W` (ขนาดแผนที่), `FOODS`, `MINSN`
